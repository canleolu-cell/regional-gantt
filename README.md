# 区域项目甘特图（欧洲 / 韩国 / 柬埔寨 / 泰国）

在线地址：https://canleolu-cell.github.io/regional-gantt/

## 工作方式

- `index.html` 是甘特图网页，版式与律动欧洲项目甘特图完全一致（状态色：绿=已完成、蓝=进行中、红=延期、灰=计划、紫=里程碑、黄=待排期；半月时间轴、深蓝阶段行、条头日期在中间栏）。
- 网页打开时直接读取同仓库的 `data.xlsx` 并实时生成图表，图头会显示数据文件的更新时间（北京时间）。
- **更新数据 = 替换 `data.xlsx`**：在本仓库页面点 `data.xlsx` → 右上角下载图标旁的编辑/替换（或 Add file → Upload files 重新上传同名文件覆盖），提交后约 1 分钟，刷新在线页即是最新版。网页本身不需要改动。
- Excel 结构约定（与模板一致，勿改）：每个区域一个 sheet（欧洲/韩国/柬埔寨/泰国）；第 1 行标题 + J 列起为半月起始日期；第 3 行为表头（编号/阶段/任务/负责人/开始日期/结束日期/状态/备注）；阶段行为深蓝整行（B 列填阶段名）；任务行填 A–H 列，下一行为条行（网页不读条行，按起止日期自动定位）。
- 空任务位（有编号、无任务名）网页自动跳过；无日期的任务显示为「待排期」；开始=结束同一天显示为菱形里程碑。
